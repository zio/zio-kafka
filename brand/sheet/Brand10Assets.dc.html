Colours, fonts and radius as CSS variables (10.2)
The files are in brand/ in the zio-kafka repository, built from the drawings on this canvas by brand/tools/build_brand.py. Cards and banners are exported at 2×. The SVGs carry their colours (no currentColor) except the mono mark, and the wordmark is converted to outlines so the logo never depends on a font being installed.

Tokens · tokens.css
/* ZIO Kafka brand tokens */ :root { --zk-bg: #FFFFFF; /* paper */ --zk-surface: #F4F5F8; /* snow: panels, code */ --zk-line: #E3E6EC; /* borders, never text */ --zk-text: #101521; /* ink */ --zk-text-2: #566074; /* slate */ --zk-accent: #E8590C; /* hub, buttons, 24 px+ type */ --zk-link: #C2410C; /* orange as text */ --zk-on-accent: #101521; /* labels on orange */ --zk-tile: #101521; /* symbol tile */ --zk-tint: #FFD3B8; /* peach: fills, highlights */ --zk-code-keyword: #C2410C; --zk-code-string: #7C2D12; --zk-font-sans: "Sora", system-ui, sans-serif; --zk-font-mono: "JetBrains Mono", ui-monospace, monospace; --zk-radius-tile: 22%; /* 26 of 120 units */ }
@media (prefers-color-scheme: dark) { :root { --zk-bg: #101521; /* ink */ --zk-surface: #171C28; /* ink 800 */ --zk-line: #232833; /* ink 700 */ --zk-text: #F4F5F8; /* snow */ --zk-text-2: #A7AEBD; /* mist */ --zk-accent: #FF8A4C; /* orange 400 */ --zk-link: #FF8A4C; --zk-on-accent: #101521; --zk-tile: #2A3245; /* charcoal */ --zk-code-keyword: #FF8A4C; --zk-code-string: #FFD3B8; /* peach */ } }
Every value comes from sections 3 and 4. Use the role names, not the hex values, so a page switches to dark mode in one place. --zk-accent on light is 3.58:1, so it never carries body text or links: those take --zk-link. Anything written on the accent takes --zk-on-accent.
