Two typefaces, one of them code

Sora carries headings, body and “Kafka” in the logo, the same pairing as ZIO Config and ZIO JSON. JetBrains Mono carries code, labels and, unusually, the “IO” of the logo, which ties the name to the code people write. Both are free and open source and load from Google Fonts.

The logo uses both
IOKafka
import zio.kafka.consumer._
Z · RING MARK
Drawn, not typed. Sized to 0.82em so the rings' outer edges match the capital height of JetBrains Mono, and nudged down 0.045em onto the baseline.
IO · JETBRAINS MONO 500
Tracking −4%. Setting IO in the code font ties the name to the line developers actually type: zio.kafka.
KAFKA · SORA 600
Tracking −2.5%. Semibold, not bold, so its strokes carry the same weight as the mono IO and the rings.
Two typefaces in one name is normally a warning sign. Here it carries meaning: the ZIO part reads as code, the Kafka part as a name. Keep the weights matched and the gap between IO and Kafka at 0.28em; never retype the logo from these settings, use the outlined files.

4.4
Code
Code uses JetBrains Mono at 15 to 16 px with a 1.7 line height and ligatures off, so <- and => look as typed. Keywords take orange 700 on light and orange 400 on dark; strings take deep orange 900 on light and peach on dark, so strings read darker or lighter than keywords, never the same orange. Type names stay in the text colour, bold where they matter. Snippets come from the zio-kafka docs (consuming topics) and README (producer).
import zio.kafka.consumer._ consumer .plainStream( Subscription.topics("topic150"), Serde.string, Serde.string ) .tap(cr => printLine(s"key: ${cr.record.key}")) .map(_.offset) .aggregateAsyncWithin( Consumer.collectOffsets, Schedule.fixed(100.millis) ) .mapZIO(_.commit) .runDrain // commit offsets in batches, every 100 ms
import zio.kafka.producer.{ Producer, ProducerSettings } for { producer <- Producer.make( ProducerSettings(List("localhost:9092")) ) _ <- producer.produce[Any, Long, String]( topic = "random-topic", key = 42L, value = "hello", keySerializer = Serde.long, valueSerializer = Serde.string ) } yield ()
Light on snow: keywords #C2410C (4.75:1), strings #7C2D12 (8.60:1), comments slate (5.80:1). Dark on #171C28: keywords #FF8A4C (7.29:1), strings peach #FFD3B8 (12.38:1), comments mist (7.65:1).
4.5
Rules
Sentence case. Headings and buttons are sentence case: “Get started”, not “Get Started”.
Names in mono. Library, type, method and topic names in running text are set in JetBrains Mono: zio-kafka, Consumer, plainStream.
One weight jump. A layout uses regular, then bold. Semibold is for small headings and for “Kafka” in the logo.
Write the name as ZIO Kafka. Two words, ZIO in capitals, in prose and headings; never “Zio”. zio-kafka is the artifact, zio.kafka the package.
